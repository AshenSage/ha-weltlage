Aktuelle Cesium-Vorschau

Das normale Release ist 2.1.1 (13.10.2026). Die Vorschau verwendet dieselbe lokal gebaute Cesium-Karte wie das HACS-Paket.

Diese Datei enthält die Startanleitung. Die frühere eingebettete Canvas-Demo aus 1.2.0 wurde durch den aktuellen Vorschauweg ersetzt.

Lokal starten

Im Repository mit Node.js 22 und Python 3.12 oder neuer ausführen:

npm ci
python -m pip install aiohttp "PyYAML>=6,<7"
npm run build
npm run preview

Danach http://127.0.0.1:8080 auf demselben Rechner öffnen. Der Vorschauprozess läuft nur auf der lokalen Loopback-Adresse.

Die Vorschau nutzt simulierte HA-Antworten, keine persönlichen Schlüssel und keine Live-Objektfeeds. Externe Kartenbilder werden tatsächlich geladen. Sie dient zur Prüfung der Oberfläche; eine HA-Installation wird damit nicht bestätigt.
